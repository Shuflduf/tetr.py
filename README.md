# tetr.py
*Tetris clone... in PYTHON!*

[Play Here](https://shuflduf.github.io/tetr.zig)

Made using pygame and pygodide.

https://github.com/user-attachments/assets/3c5a21ec-7ae5-4933-9afc-60f2c8f9317d


# Features
- Piece movement
- Line clears
- SRS kicks
- DAS and ARR
- Lock delay
- 7-Bag piece system
- Auto-retry
- UI

# Controls
- A: Move left
- D: Move right
- Left arrow: Counter-clockwise
- Right arrow: Clockwise
- S: Hard drop
- W: Soft drop
- Left shift: Hold piece
